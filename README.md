# Faselu（ファセル）

**分類されない、あなた自身を、探しに。**

---

## このサービスは何か

Faselu は、AI と 1 対 1 で対話しながら、**自分自身を深く掘り下げていく自己分析セッション**です。

ボタンを押せば数秒で結果が出る「診断ツール」ではありません。あらかじめ用意された 16 タイプや 5 因子のどれかに振り分けるものでも、強みのラベルを並べて終わるものでもありません。

このサービスがやろうとしているのは、ただ一つ。

> **「自分は何者か」を問う時間を、ちゃんと使ってもらうこと。**

AI が代わりに答えを出してくれるわけではありません。AI は逃げずに付き合うだけで、考えるのは最後まで自分です。

---

## なぜ作ったか

世の中の AI ツールはほとんどが「効率化・時短・便利」に向かっています。人間がやるべきことを AI が肩代わりする方向です。

Faselu はその逆を狙っています。

> **人間がやるべきことから、AI が逃げずに付き合う。**

自分と向き合うことは、本来とても面倒で、時間がかかって、しんどい作業です。それを AI が「効率化」してしまうと、結局何も残らない。だから Faselu はあえて時間をかけ、あえて踏み込み、あえて答えにくいことを聞きます。

また、世の中の自己分析サービスの多くは「数分で簡単にタイプが分かる」ことを売りにしています。Faselu はその対極で、**分類されないあなた自身を、時間をかけて探しに行く** ことに価値を置きます。

---

## 体験の特徴

### 1. 本気で向き合う対話

セッションはチャット形式で進みます。AI は次のような姿勢で対話を進めます。

- **褒めるだけ、慰めるだけにしない**
- **無難な共感やテンプレ応答は避ける**
- **矛盾は指摘するし、避けてきたものにも触れる**
- **共感だけで終わらせず、必ず次の問いを置く**

冒頭で AI はこう宣言します。

> あなたと向き合います。
> 答えにくい問いもします。
> 矛盾は指摘しますし、避けてきたものにも触れます。
>
> 短く答えるほど、見えてくる自分は小さくなります。
> 事例や気持ちまで含めて、長めに話してください。

### 2. 対話 → 最終分析の 2 フェーズ構造

セッションは内部的に 2 つのモードに分かれて動きます。

**対話モード（素材集めフェーズ）**
AI は素材を集めることに専念し、過剰な解釈や心理学的なラベル貼りは控えます。基本は **simple reflection**（言葉に近い反映）で受け止め、すぐに次の問いを置きます。9 つの領域（性格・人間関係・恋愛・価値観・将来像・コンプレックス・ストレス要因・他人への違和感・自分のこだわり）にバランスよく触れていきます。

**最終分析モード**
9 領域に十分触れたと AI が判断したタイミングで、自動的に最終分析に移行します。ここで初めて対話全体を統合し、踏み込んだ分析を返します。

### 3. 4 つの観点から分析する

最終分析は、以下の 4 つの観点を独立したセクションとして使います。思考から無意識、対人、欲求まで、人物像を立体的に描くための軸です。

- **思考の癖**（認知パターン）— 発言の中に出てきた考え方の偏り（白黒思考・破局化・「べき」思考など）を、専門用語を使わず平易な日本語で言語化。
- **無意識のパターン** — ユーザー自身が自覚していないが対話の中で繰り返し現れた行動・思考の癖。テキスト対話ならではの「無意識の漏れ」を観察対象にする。何度も繰り返し出てきた語、質問されていないのに否定形で返した話題、即答した話題とためらった話題の差、言葉の強度と話題の重さの不一致など。
- **対人パターン** — 親密圏（家族・恋愛・親友）と社会圏（仕事・知人）で接近と回避の戦略がどう変わるか。行動心理・愛着・対人関係をここに統合。
- **欲求の核** — 本当に欲しいものと本当に避けたいもの。承認 / 安心 / 支配 / 自由 / 創造 / 繋がり / 独立 / 一貫性 などの軸で、表に出る「やりたい」と内側の「本当はこうしたい」のズレを指摘。

分類で終わらせない方針として、「あなたは○○型です」のような断定的なラベリングは避け、「〜の傾向が見えます」「〜の側面があります」のような留め方を基本にします。

### 4. ふたつのアウトプット

セッション終了時、2 種類の成果物が生成されます。

#### カード（持ち歩く用 / シェア用）

- 3:4 縦長の黒い厚紙のグリーティングカード風
- 縁は AI が分析結果から選んだ **個別の色のグラデーション**
- 載せる項目:
  - **キーフレーズ**: その人を象徴する一文
  - **CHARACTERISTICS**: 特徴 3 点（抽象度を上げる）
  - **QUESTION TO SELF**: これから自分に問い続けるべき問い 1 つ

シェアは煽りません。SNS シェアボタンは置かず、「**信頼している人にだけ見せてください**」と添えています。カードは画像として保存できます。

#### 詳細レポート（本人だけが見る）

4 観点（思考の癖・無意識のパターン・対人パターン・欲求の核）を中心に、強みと弱さ、向いている環境、本人がまだ気づいていない核心まで含む、AI の全分析を本人専用に整形したもの。PDF として書き出せます。

### 5. 縁の色は、その人専用に生成される

カードの縁のグラデーションは、AI が分析テキストから核となる性質を 2〜4 個抽出し、それぞれを色に翻訳して組み合わせます。色域に縛りはなく、淡い色・鮮やかな色・パステル・ネオン・メタリックまで含めて、毎回その人専用の色が決まります。

線形・放射状・円錐などのグラデーションパターンも、その人の性質に合わせて選ばれます。

## サービスのスタンス

### 会話内容はサーバーに保存しない

セッション中の会話は AI とのリクエスト・レスポンスにのみ使われ、サーバーに永続化されません。ブラウザを閉じればセッションは消えます（ローカルストレージ上の対話履歴のみ、リロード復元のために一時保持されます）。

ただし、入力された内容は Google の Gemini / Gemma API に送信されます。Google 側のポリシーに従って学習に使われる可能性があるため、氏名・住所・連絡先など個人を特定できる情報の入力は避けてください。

### 安全弁

自傷・自殺念慮、重度のメンタル不調、虐待・DV・性暴力被害、医療・カウンセリング領域への踏み込みを検知した場合、AI はその時点でセッションを即終了します。ここまでの会話は保存されません。

## 想定する利用者

「自分を知りたい」と思う人なら、年齢・職業・状況は問いません。

入り口は広く設計し、体験の深さで自然に篩い分ける方針です。重ければ離脱して構わないし、合わなければそれでいいというスタンスです。

> ⚠️ **注意**: 踏み込んだ指摘を含むセッションです。**心身が弱っている状態のときは利用を控えてください。**

### モード別モデル運用

対話の応答テンポと最終分析の品質を両立させるため、モードによって使うモデルを切り替えています。

- **対話モード**: `gemma-4-26b-a4b-it`（軽量で応答が速い、無料 tier でレート制限が緩い）
- **最終分析モード**: `gemini-3.1-flash-lite`（レポート品質を担保しつつ、無料 tier 内で安定）

Google AI Studio API の 500 / 503 transient エラーに対しては、ステータス別の即時リトライ機構（500 は 0ms、503/502/504 は段階的、429 は指数バックオフ）を `lib/google-direct.ts` に実装しています。

## セットアップ

### 必要なもの

- Node.js 20 以上
- Google AI Studio で発行した API キー（[取得はこちら](https://aistudio.google.com/apikey)）

### 手順

```bash
# 依存関係のインストール
npm install

# 環境変数の設定
cp .env.local.example .env.local
# .env.local を開き、GOOGLE_GENERATIVE_AI_API_KEY に取得した API キーを設定

# 開発サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## 環境変数

| 変数名                         | 必須 | デフォルト                | 説明                                                                                          |
| ------------------------------ | ---- | ------------------------- | --------------------------------------------------------------------------------------------- |
| `GOOGLE_GENERATIVE_AI_API_KEY` | ✅   | —                         | Google AI Studio で発行した API キー                                                          |
| `FASELU_DIALOGUE_MODEL`        | —    | `gemini-3.1-flash-lite`   | 対話モード用モデル。推奨は `gemma-4-26b-a4b-it`                                               |
| `FASELU_FINAL_MODEL`           | —    | `gemini-3.1-flash-lite`   | 最終分析モード用モデル                                                                        |
| `FASELU_PROVIDER`              | —    | `gemini`                  | LLM プロバイダ。`gemini` または `groq`                                                        |
| `FASELU_GEMINI_MODEL`          | —    | `gemini-3.1-flash-lite`   | 旧式の単一モデル指定。`FASELU_DIALOGUE_MODEL` / `FASELU_FINAL_MODEL` 未指定時のフォールバック |
| `GROQ_API_KEY`                 | —    | —                         | `FASELU_PROVIDER=groq` のときのみ必要                                                         |

## デプロイ

Vercel での運用を想定しています。

1. Vercel ダッシュボードでこのリポジトリを Import
2. Environment Variables に以下を設定:
   - `GOOGLE_GENERATIVE_AI_API_KEY`（必須）
   - `FASELU_DIALOGUE_MODEL=gemma-4-26b-a4b-it`（推奨）
   - `FASELU_FINAL_MODEL=gemini-3.1-flash-lite`（推奨）
3. Deploy

`app/api/chat/route.ts` は `maxDuration = 60` を指定しており、Vercel Hobby の 60 秒タイムアウト内に応答が完結するよう設計されています。
